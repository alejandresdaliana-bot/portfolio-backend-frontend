# Tech Challenge: Enterprise Logistics Architecture (Laravel + .NET + Angular)

Este repositorio contiene módulos de código funcional diseñados para demostrar habilidades técnicas de nivel Semi Senior en la estructuración de arquitecturas limpias, consumo de APIs REST y patrones de diseño modernos.

El proyecto simula un módulo de **Gestión y Monitoreo de Embarques Logísticos**, dividiéndose en tres componentes principales:

1. **`/laravel-api`**: Backend ágil encargado de la gestión de logs, multi-tenant y respuestas JSON optimizadas.
2. **`/.net-api`**: API empresarial robusta para la validación de negocio y persistencia de datos.
3. **`/angular-frontend`**: Interfaz de usuario interactiva y reactiva basada en componentes y servicios.

---

## 🛠️ Stack Tecnológico Utilizado
- **Backend:** PHP (Laravel 10/11), C# (.NET 8)
- **Frontend:** TypeScript (Angular 16+), Bootstrap 5
- **Base de Datos:** SQL (Arquitectura relacional)
